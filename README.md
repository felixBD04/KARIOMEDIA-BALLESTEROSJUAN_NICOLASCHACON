# Kario Media — Panel de Gestión de Proyectos

Aplicativo web frontend que muestra el panel de gestión de proyectos y módulos de la empresa **Kario Media**, dedicada a licitaciones públicas y privadas en varios nichos de negocio.

Proyecto desarrollado en colaboración con un compañero de equipo (Nicolás Chacón).

## Funcionalidad

Continuación de un proyecto frontend existente. Construye:

- **Panel principal** de gestión de proyectos
- **Módulos por área** de negocio
- **Vistas de proyectos activos** con estados y detalles
- Navegación entre páginas internas

## Stack

- HTML5 · CSS3 · JavaScript (vanilla)
- Estructura modular por páginas y componentes

## Estructura

```
├── index.html      # Vista principal del panel
├── pages/          # Vistas internas
├── css/            # Estilos por componente
└── media/          # Imágenes y recursos
```

## Contexto

Proyecto académico desarrollado como práctica frontend de aplicaciones empresariales reales en Campus Lands, sobre la base de un proyecto previo que tuvo que ser continuado y extendido.

- Trabajo colaborativo con Git en un proyecto compartido
